02 How it works

How API example checks work

Point the linter at existing documentation. Then choose the operation or schema for each example.

  1. 01

    Extract examples

    Find fenced JSON and curl bodies in Markdown and examples inside OpenAPI 3.x files.

    docs/**/*.md
  2. 02

    Choose a schema or operation

    Use a named schema or an operation request or response.

    operation=createPet
  3. 03

    Report each mismatch

    Return the file, line, JSON pointer, and mismatch in text, JSON, or GitHub format.

    $/retired_field

05 Scope and privacy

What the linter does not do

It does not run curl commands or fetch remote references. Mock requests happen only when you provide a permitted local host.

06 CI setup

Add the linter to CI

Add one configuration file and one CI command. A failed check names the example that needs repair.

cargo install --git https://github.com/B-Divyesh/sf-api-example-linter.git
.api-example-linter.json
{
  "spec": "openapi.yaml",
  "inputs": ["docs"],
  "operation": "createPet",
  "direction": "request"
}
api-example-linter check --format github
