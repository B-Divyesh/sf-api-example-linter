Policy Effective 27 August 2026

Privacy, by absence.

API Example Linter does not collect, transmit, or sell personal data.

CLI

The CLI runs locally. It reads only the files and configuration paths you provide. It has no telemetry. Network access occurs only when you explicitly use --mock-base-url, and only to the hostname you allow.

Website

This site uses no analytics, advertising, cookies, forms, third-party scripts, or hosted fonts. A service worker stores public site files in your browser for offline access. You can remove that cache through your browser’s site-data controls.

Contact

For a privacy question, open an issue in the public source repository without including secrets or personal data.
