Privacy policy

Default checks run on your computer and make no network requests.

CLI files

The CLI reads the input, contract, and configuration paths you provide. It has no telemetry.

Optional mock requests

Network access starts only when you pass --mock-base-url. The CLI accepts loopback hosts unless you explicitly allow another hostname.

Website data

This site uses no analytics, advertising, cookies, forms, or third-party runtime code. Its service worker caches public site files for offline use.

The demo uses only demo: session storage. Reset demo removes that namespace, and Start for real leaves demo mode.

Remove cached files

Use your browser site-data controls to remove the service-worker cache.
